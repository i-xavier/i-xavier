Cursando o 4º semestre de ADS no IFSP, com sólida base em Programação Orientada a Objetos (C#), desenvolvimento em C ANSI e modelagem de bancos de dados relacionais. Concluí o programa **Transforme-se** da Serasa Experian (280h), com foco em desenvolvimento de sistemas, modelagem de banco de dados, testes e versionamento.
